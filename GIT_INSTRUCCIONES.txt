================================================================================
INSTRUCCIONES PARA SUBIR A GIT
================================================================================

Repositorio: https://github.com/Joel-Lopez-Dev/proyecto_fse_gamecube.git

================================================================================
PASO 1: CONFIGURAR GIT (Primera vez)
================================================================================

En la PC (en la carpeta del proyecto):

git config --global user.name "Tu Nombre"
git config --global user.email "tu.email@gmail.com"

================================================================================
PASO 2: INICIALIZAR REPOSITORIO
================================================================================

git init
git add .
git commit -m "Inicial: GameCube Proyecto FSE - Adaptado para Raspberry Pi"

================================================================================
PASO 3: CONECTAR REMOTO
================================================================================

git remote add origin https://github.com/Joel-Lopez-Dev/proyecto_fse_gamecube.git

================================================================================
PASO 4: SUBIR AL REPOSITORIO
================================================================================

git push -u origin main

Si pide contraseña, usa tu token de GitHub (Settings → Developer Settings → Personal access tokens)

FLUJO COMPLETO
================================================================================

# 1. En PC
cd d:\proyecto_fse\simon_xbox_project
git init
git add .
git commit -m "Initial commit: GameCube adaptado para Rasp"
git remote add origin https://github.com/Joel-Lopez-Dev/proyecto_fse_gamecube.git
git branch -M main
git push -u origin main

# 2. En Rasp
cd /home/pi
git clone https://github.com/Joel-Lopez-Dev/proyecto_fse_gamecube.git
cd proyecto_fse_gamecube
sudo bash setup-rasp.sh
mkdir videos/
# (Coloca gamecube.mp4 aquí)
sudo systemctl start gamecube

# 3. Verificar
# Abre: http://<IP-RASP>:8000
